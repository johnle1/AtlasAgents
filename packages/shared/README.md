# @loopycode/shared

Shared types and diff-rendering utilities used by both [`loopycode`](https://www.npmjs.com/package/loopycode) (CLI client) and [`loopycode-server`](https://www.npmjs.com/package/loopycode-server) (RSocket server).

Not intended for standalone use — install one of the packages above instead. This package is published so those two can each depend on it independently rather than bundling a duplicate copy.
