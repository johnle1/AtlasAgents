# @atlasagents/shared

Shared types and diff-rendering utilities used by both [`atlasagents`](https://www.npmjs.com/package/atlasagents) (CLI client) and [`atlasagents-server`](https://www.npmjs.com/package/atlasagents-server) (RSocket server).

Not intended for standalone use — install one of the packages above instead. This package is published so those two can each depend on it independently rather than bundling a duplicate copy.
